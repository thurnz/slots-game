# 🎰 Slots Game (PixiJS)

A simple **slot machine test game** built using [PixiJS](https://pixijs.com/).  
This project demonstrates how to use PixiJS for 2D rendering, sprite animation, and basic game logic with **Webpack**.

---

## 🚀 Setup

### 1. Clone the repository
```bash
git clone https://github.com/thurnz/slots-game.git
cd slots-game
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the project in development mode
```bash
npm start
```
This will launch Webpack Dev Server in development mode.

### 4. Build for production
```bash
npm run build
```
The compiled files will be output to the /dist folder.
